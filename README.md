# 🍔 Esquina do Sabor - Sistema de Gestão e Cardápio Digital

Este projeto é um ecossistema digital completo para lanchonetes, desenvolvido para automatizar desde a escolha do produto pelo cliente até o gerenciamento da produção na cozinha em tempo real.

## 🚀 Funcionalidades
- **Cardápio Digital Interativo:** Layout moderno e responsivo focado na experiência do usuário mobile.
- **Carrinho de Compras:** Lógica para adição de itens, observações e seleção de método de entrega (Entrega ou Retirada).
- **Integração Real-time:** Uso do **Firebase Firestore** para envio e recebimento de pedidos instantâneos, sem necessidade de atualizar a página.
- **Painel Administrativo:** Gestão de fluxo de pedidos com colunas de status (Pendente, Preparando e Finalizado) e alertas sonoros.
- **Relatórios de Vendas:** Dashboard integrado que calcula o faturamento total dos pedidos finalizados no dia.

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3 (Flexbox/Grid/Variables).
- **Lógica de Programação:** JavaScript Vanilla (ES6+ Modules).
- **Banco de Dados / Backend:** Google Firebase (Firestore).
